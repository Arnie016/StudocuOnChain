## Loki Unchained Architecture Assets

- `studocu-onchain-architecture.mmd` - Mermaid definition of the end-to-end flow emphasizing the uploader reward loop.

### Preview the Diagram Locally

```bash
cd /path/to/StudocuOnChain
npm install --global @mermaid-js/mermaid-cli
mmdc -i docs/architecture/studocu-onchain-architecture.mmd -o docs/architecture/studocu-onchain-architecture.png
```

Then open the generated PNG or embed it elsewhere (the root README renders the Mermaid source directly).
